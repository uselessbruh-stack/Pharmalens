Abstract

Project Overview

Drug discovery costs $1–2 billion and takes 10–15 years per drug. Testing every drug-protein combination experimentally is infeasible.

PharmaLens uses machine learning to predict binding affinity from molecular structure and protein sequences. It compares 7 models on the KIBA benchmark and provides SHAP explainability for interpretable predictions.

Introduction

Problem · Solution · Scope

🚨 Problem

  • Experimental screening is slow and costs billions
  • Combinatorial explosion: thousands of drugs × hundreds of proteins
  • Most AI models lack interpretability

💡 Solution

  • ML framework predicting binding from SMILES + protein sequence
  • 7-model comparison: baselines → XGBoost → CNN → GNN
  • SHAP explainability for every prediction

🎯 Purpose

  • Accelerate early-stage drug candidate prioritization
  • Provide trustworthy, interpretable predictions
  • Enable batch screening for researchers

📐 Scope

  • KIBA benchmark dataset (kinase inhibitors)
  • Continuous binding affinity prediction
  • Web app for interactive prediction and screening
  • Does not replace experimental validation

Functional Requirements

System Capabilities

IDRequirement
FR-01The system shall allow users to input drug molecules via SMILES string or by selecting from the KIBA dataset.
FR-02The system shall allow users to input protein targets via amino acid sequence or by selecting from the dataset.
FR-03The system shall predict binding affinity scores for a given drug–target pair using the trained ML model.
FR-04The system shall validate user inputs (SMILES validity via RDKit, sequence format) and display appropriate error messages for invalid entries.
FR-05The system shall perform batch screening across multiple drug × target combinations and return ranked results.
FR-06The system shall provide SHAP-based explanations for each prediction, showing which molecular features contributed most.
FR-07The system shall display drug information including molecular weight, LogP, TPSA, hydrogen bond donors/acceptors, and structural fingerprint details.
FR-08The system shall allow users to compare multiple ML models (Ridge, RF, XGBoost, DeepDTA, GraphDTA) based on evaluation metrics.
FR-09The system shall display dataset exploration views including score distributions, drug/target counts, and interaction statistics.
FR-10The system shall expose a REST API (FastAPI) for programmatic access to prediction, screening, and explanation endpoints.
FR-11The system shall provide a web-based dashboard for interactive prediction, screening, model comparison, and dataset exploration.
FR-12The system shall display appropriate disclaimers indicating that predictions are computational and do not replace experimental lab validation.

Score Range

💊 Drug → 1,034D

  • 10 descriptors — MW, LogP, TPSA, HBD, HBA, rotatable bonds, aromatic rings, Csp3, heavy atoms, rings
  • 1,024-bit Morgan FP — circular substructure (ECFP4, radius=2)

🧬 Protein → 420D

  • AAC (20D) — frequency of each amino acid
  • DPC (400D) — frequency of amino acid pairs (20×20)

Per pair: concat(drug₁₀₃₄, protein₄₂₀) = 1,454D input vector

Key Findings

  • Morgan FP bits — strongest predictors; specific substructures drive binding
  • LogP, MW, TPSA — top descriptors; lipophilicity and size matter
  • Dipeptide composition — main protein-side signal
  • Every prediction decomposable via waterfall plots
