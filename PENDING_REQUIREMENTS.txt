NON-FUNCTIONAL REQUIREMENTS — NOT YET ACHIEVED
------------------------------------------------

NFR-02  Availability
        - Currently runs only locally (localhost)
        - No deployment to cloud or production server
        - No uptime monitoring

NFR-04  Security
        - No input sanitization on API endpoints
        - No rate limiting configured
        - No authentication/authorization

NFR-08  Scalability
        - Not tested under concurrent load
        - No load balancing or caching
        - Single-process Uvicorn server

NFR-10  Compatibility
        - Only tested on Chrome
        - No cross-browser testing done (Firefox, Edge, Safari)

NFR-11  Responsiveness
        - Web dashboard not tested on tablet/mobile viewports
        - May not render properly on smaller screens

NFR-14  Data Integrity
        - No checksums for model artifacts
        - No version tracking system for models/datasets
        - Model files are plain pickle/joblib with no integrity checks
